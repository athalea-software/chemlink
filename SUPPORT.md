# Getting help

- **Documentation:** [athalea.co/chemlink/docs](https://athalea.co/chemlink/docs)
  covers installation, every command and option, the pipelines, HPC deployment
  and troubleshooting.
- **Diagnose your environment:** `chemlink doctor` shows which tools, GPUs and
  paths ChemLink found. Include its output in any report.
- **Bugs and feature requests:** open an
  [issue](https://github.com/athalea-software/chemlink/issues/new/choose).
- **Usage questions and installation help:**
  [support@athalea.co](mailto:support@athalea.co).
- **Research collaborations:** [research@athalea.co](mailto:research@athalea.co).
- **Commercial licensing:** [sales@athalea.co](mailto:sales@athalea.co).
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not open a public
  issue.
